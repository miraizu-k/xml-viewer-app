# セキュリティ

脆弱性を見つけたら、公開の Issue ではなく、GitHub の非公開の報告で知らせてください。

1. このリポジトリの「Security」タブを開く
2. 「Report a vulnerability」を押す

再現に文書が必要なときは、実物の公文書ではなく、個人情報を架空のものに置き換えたデータを使ってください。
修正は最新のリリースに対して行います。

## Reporting a vulnerability

Please report vulnerabilities privately with the "Report a vulnerability" button on the Security tab, not in public issues.
Do not attach real documents that contain personal information; use made-up data to reproduce the problem.
Fixes are made against the latest release.
