    「送る」に追加 右クリックの「送る」から開けます。複数のファイルを選ぶと、1 つのウィンドウにまとめて開きます。
    右クリックメニューに追加 zip と XML の右クリックに「XML Viewer で開く」を足します。Windows 11 では「その他のオプションを確認」の中に出ます。
    「プログラムから開く」の候補に登録 XML と zip の「プログラムから開く」の一覧に、このアプリを出します。
    XML をダブルクリックで開くには
    1. 上の「プログラムから開く」の候補に登録する
    2. XML を右クリックして「プログラムから開く」→「別のプログラムを選択」
    3. XML Viewer を選んで「常に使う」
